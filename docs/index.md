# 个人知识库

把正在处理的问题、长期积累的知识、项目决策和复盘记录放在同一个地方。

## 今日工作台

| 入口 | 内容 |
| --- | --- |
| [Inbox](/notes/inbox) | 临时想法、未分类材料和待处理链接 |
| [笔记总览](/notes/) | 长期笔记、阅读笔记和技术笔记 |
| [项目总览](/projects/) | 项目背景、关键决策、里程碑和复盘 |
| [资源库](/resources/) | 工具、链接、清单和参考资料 |
| [每周回顾](/archive/weekly-review) | 本周产出、问题和下周重点 |

## 知识地图

| 分区 | 适合记录 |
| --- | --- |
| [Notes](/notes/) | 需要持续演化的概念、方法、问题和结论 |
| [Projects](/projects/) | 有明确目标、周期、交付物和责任边界的事项 |
| [Resources](/resources/) | 可复用的工具、资料、命令、模板和检查清单 |
| [Archive](/archive/) | 已完成事项、阶段总结、周报、月报和历史记录 |

## 近期维护

- 每天把零散材料先放进 [Inbox](/notes/inbox)。
- 每周整理一次 Inbox，把可沉淀的内容移动到主题笔记或项目页面。
- 项目结束后补齐复盘，再移入 [归档](/archive/)。
