# Web3 基础概念

## 核心概念

| 概念 | 简单解释 | 需要注意 |
| --- | --- | --- |
| 区块链 | 按时间顺序记录交易的数据网络 | 不等于所有数据都安全或真实 |
| 公链 | 任何人可参与读取、发送交易或验证的链 | 手续费、拥堵、生态差异很大 |
| 智能合约 | 部署在链上的程序 | 代码漏洞可能导致资金损失 |
| 钱包 | 管理地址、签名和资产交互的工具 | 钱包不真正“存币”，资产记录在链上 |
| 私钥 | 控制地址资产的关键凭证 | 丢失或泄露都可能造成不可逆损失 |
| 助记词 | 用来恢复钱包的一组单词 | 绝不能截图、上传或发给任何人 |
| Gas fee | 链上交易手续费 | 高峰期成本可能明显上升 |

## 一句话理解

- 区块链像公开账本。
- 钱包像签名工具。
- 私钥和助记词像最高权限钥匙。
- 智能合约像自动执行的链上程序。
- 交易一旦上链，通常很难撤回。
