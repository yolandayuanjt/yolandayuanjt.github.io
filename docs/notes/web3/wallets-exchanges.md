# 钱包与交易所

## 钱包类型

| 类型 | 适合用途 | 风险 |
| --- | --- | --- |
| 托管钱包 | 交易所账户、上手简单 | 平台风险、账户冻结、被盗 |
| 非托管热钱包 | 链上交互、DeFi、NFT | 私钥泄露、钓鱼签名、恶意合约 |
| 硬件钱包 | 长期保存资产 | 设备保管、备份管理、操作复杂 |

## 安全习惯

- 助记词不截图、不上传云盘、不发给任何人。
- 大额资产不要长期放在单一平台或单一热钱包。
- 链上交互前检查网址、合约地址和授权内容。
- 不随便签名看不懂的交易。
- 定期检查钱包授权，撤销不再使用的高风险授权。
- 先用小额测试转账，再进行大额操作。
