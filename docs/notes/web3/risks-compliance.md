# 风险与合规

> 虚拟货币相关风险可能变化很快。本页用于建立检查框架，不替代监管、法律、税务或投资意见。

## 风险分类

| 风险 | 说明 | 检查问题 |
| --- | --- | --- |
| 市场风险 | 价格大幅波动、流动性不足 | 如果下跌 50%，是否能承受？ |
| 平台风险 | 交易所、托管方、借贷平台出问题 | 资产是否过度集中在一个平台？ |
| 私钥风险 | 助记词丢失、泄露、被盗 | 是否有离线备份？ |
| 合约风险 | 智能合约漏洞、管理员权限滥用 | 是否了解合约和审计情况？ |
| 诈骗风险 | 钓鱼网站、假客服、假空投、恶意签名 | 是否确认来源和网址？ |
| 稳定币风险 | 脱锚、赎回受限、储备不足 | 是否了解发行方和储备机制？ |
| 跨链风险 | 跨链桥被攻击或暂停 | 是否必须跨链？金额是否可控？ |
| 监管风险 | 不同地区规则不同，可能影响交易和服务 | 是否了解所在地相关要求？ |

## 操作前检查

- [ ] 这笔操作的目的是什么？
- [ ] 金额是否在可承受损失范围内？
- [ ] 是否确认官网、合约地址和网络？
- [ ] 是否需要先小额测试？
- [ ] 是否记录了交易哈希和来源？
- [ ] 是否理解最坏情况？

## 不做清单

- 不记录或上传助记词、私钥。
- 不点击陌生人发来的空投、客服、验证链接。
- 不在不理解授权内容时签名。
- 不因为短期涨跌临时改变风险上限。
- 不把社交媒体热度当作投资依据。
