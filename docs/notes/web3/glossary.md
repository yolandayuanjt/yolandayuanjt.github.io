# Web3 术语表

| 术语 | 解释 |
| --- | --- |
| Address | 链上地址，用于接收或发送资产 |
| Airdrop | 空投，项目方向用户发放代币或权益 |
| AMM | 自动做市商，常见于去中心化交易所 |
| APR | 年化利率，不考虑复利 |
| APY | 年化收益率，通常考虑复利 |
| Bridge | 跨链桥，用于在不同链之间转移资产或信息 |
| CEX | 中心化交易所 |
| DEX | 去中心化交易所 |
| DeFi | 去中心化金融 |
| Gas | 链上交易手续费 |
| Governance Token | 治理代币，通常用于协议治理投票 |
| Layer 1 | 底层公链 |
| Layer 2 | 构建在 Layer 1 之上的扩容网络 |
| Liquidity | 流动性，反映资产买卖是否容易 |
| Meme coin | 主要由社群、叙事或网络文化驱动的代币 |
| NFT | 非同质化代币 |
| Private Key | 私钥，控制链上地址资产的关键凭证 |
| Seed Phrase | 助记词，用于恢复钱包 |
| Slippage | 滑点，预期成交价与实际成交价的差异 |
| Stablecoin | 稳定币，通常试图锚定美元等法币 |
| Staking | 质押，通常用于获得网络奖励或参与安全机制 |
| TVL | Total Value Locked，协议锁仓总价值 |
| Wallet | 钱包，用于管理地址和签名交易 |
