# 个人知识库

基于 VitePress 的个人知识库，用 Markdown 管理笔记、项目、资源和归档。

## 本地开发

```bash
npm install
npm run docs:dev
```

## 构建与预览

```bash
npm run docs:build
npm run docs:preview
```

## 内容结构

- `docs/notes/`：长期笔记、阅读笔记、技术笔记和待整理内容
- `docs/projects/`：项目记录、决策和复盘
- `docs/resources/`：工具、链接、清单和参考资料
- `docs/archive/`：周回顾、月回顾和历史归档
